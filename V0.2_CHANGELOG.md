# Project Nucleus v0.2

## Added
- Central finite-difference numerical gradient checking.
- Structured results with analytical/numerical gradients, maximum absolute and relative errors, and tolerance-based pass/fail.
- Validation for scalar outputs, finite inputs/outputs, and numerical-check parameters.
- Tests covering arithmetic, powers, broadcasting, matrix multiplication, reductions, and nonlinear activations.

## Scope
This release adds a verification utility; it does not change the Tensor engine's runtime behavior or claim support for operations not present in v0.1.
