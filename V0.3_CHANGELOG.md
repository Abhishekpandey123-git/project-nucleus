# Project Nucleus v0.3

## Added
- `Parameter`, a trainable Tensor abstraction.
- Recursive, duplicate-safe `Module.parameters()` discovery.
- `no_grad()` context manager for inference/evaluation graph suppression.
- SGD momentum and validated `state_dict()` / `load_state_dict()` support.
- Tests for parameter discovery, graph suppression, gradient accumulation/reset, optimizer momentum and state restoration.

## Compatibility
- `Parameter` remains a `Tensor` subclass.
- Existing Linear, Sequential, trainer, loss, and Tensor APIs are retained.
- Existing `Tensor.backward()` accumulation semantics are explicitly tested.

## Limitations
- Optimizer state does not serialize model weights.
- The engine remains NumPy/CPU-based and matrix multiplication remains 2-D.
