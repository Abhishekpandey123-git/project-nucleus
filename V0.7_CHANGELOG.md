
# v0.7 — Image-Text Alignment

## Added
- CNN-based `ImageEncoder` using Conv2D, ReLU and AvgPool2D.
- `TextEncoder` using token embeddings and mean pooling.
- `ImageTextAlignmentModel` combining image/text encoders and projection heads.
- Pairwise cosine-similarity matrix with L2 normalization.
- Symmetric image-to-text and text-to-image contrastive loss.
- Bidirectional Recall@K retrieval metrics.
- Synthetic end-to-end image-text training demonstration.

## Testing
- Image encoder forward and backward tests.
- Text encoder forward and backward tests.
- Combined model forward and backward tests.
- Contrastive loss and gradient validation.
- Full repository test suite: 75 passed.

## Notes
The training demonstration uses synthetic paired data. Its loss reduction is not a measure of real-world retrieval accuracy or generalization.
