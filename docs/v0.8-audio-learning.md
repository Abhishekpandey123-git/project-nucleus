# Project Nucleus v0.8 — Audio Learning

## Scope

v0.8 adds a CPU/NumPy audio classification foundation. It is an educational
spectrogram-based classifier, not a production speech-recognition system.

## Included

- Per-waveform peak normalization.
- Short-time Fourier transform (STFT) magnitude spectrograms using Hann or
  rectangular windows.
- `AudioDataset` with deterministic mini-batch iteration.
- `AudioEncoder` that projects spectrogram frames and mean-pools over time.
- `AudioClassifier` with trainable classification head.
- Stable cross-entropy and accuracy metrics.
- Synthetic tone-vs-tone classification demo.

## Data shapes

- Waveforms: `(batch, samples)` mono floating-point arrays.
- Spectrograms: `(batch, frequency_bins, frames)`.
- Classifier logits: `(batch, classes)`.

The STFT is NumPy preprocessing and does not participate in autograd. The
spectrogram encoder and classification head are trainable through Nucleus
Tensor operations.

## Run

```bash
python examples/audio_classification_demo.py --epochs 25
pytest -q tests/test_audio_v08.py
```

## Limitations and next steps

- No audio file decoder is bundled; supply waveform arrays from a source you
  control.
- No sample-rate conversion, stereo mixing, mel filterbank, MFCC, streaming,
  speech recognition, text-to-speech, or audio-text alignment yet.
- The synthetic demo validates the training pipeline, not real-world accuracy.
