
# v0.7 — Image-Text Alignment

## 1. Objective

Project Nucleus v0.7 introduces a CLIP-style contrastive learning workflow. It learns a shared embedding space for paired image and text inputs.

Matching image-text pairs are treated as positive pairs. Other examples in the same batch act as negative pairs.

## 2. Architecture

### Image encoder

The `ImageEncoder` uses:
- Conv2D
- ReLU
- AvgPool2D
- A second Conv2D and ReLU
- Global average pooling

Input format: `(batch, channels, height, width)`.

The current implementation requires image height and width of at least 8 pixels.

### Text encoder

The `TextEncoder` uses:
- Embedding lookup
- Mean pooling across the sequence

Input format: `(batch, sequence_length)`.

It currently does not use a Transformer or tokenizer.

### Projection heads

Separate trainable Linear layers project image and text features into a shared embedding dimension.

The `ImageTextAlignmentModel` combines both encoders and projection heads.

## 3. Contrastive learning objective

For a batch of N paired examples:

- Compute pairwise cosine similarity between image and text embeddings.
- Divide similarity logits by the temperature.
- Calculate image-to-text cross-entropy using diagonal positive targets.
- Calculate text-to-image cross-entropy using diagonal positive targets.
- Average both directional losses.

The diagonal entries represent matching pairs. Off-diagonal entries represent in-batch negatives.

## 4. Retrieval metrics

`recall_at_k` reports:
- Image-to-text Recall@K
- Text-to-image Recall@K

Evaluate retrieval on held-out paired examples. Training-batch retrieval must not be presented as test performance.

## 5. Training demonstration

Run:

```bash
python examples/image_text_alignment_demo.py --epochs 200 --learning-rate 0.001
```

The included demonstration uses synthetic paired data. It verifies end-to-end optimization but does not establish real-world retrieval accuracy or generalization.

## 6. Testing

Run the full repository suite:

```bash
pytest -q
```

The current verified result is 75 passing tests.

## 7. Limitations and future work

- Add a tokenizer and real image-caption dataset.
- Explore Transformer-based text encoding.
- Evaluate on held-out image-text pairs.
- Report Recall@1, Recall@5 and Recall@10.
- Investigate generalization beyond the synthetic training batch.
