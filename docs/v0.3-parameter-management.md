# Project Nucleus v0.3 — Parameter Management and Training Control

## Parameter
`Parameter` is a `Tensor` subclass that defaults to `requires_grad=True`. Use it for trainable weights and biases.

## Module parameter discovery
`Module.parameters()` recursively discovers `Parameter` instances held directly, inside nested modules, or inside lists, tuples, and dictionaries. Duplicate references are returned only once.

## no_grad
Use `with no_grad():` around inference/evaluation computations. Operations created in the context do not retain an autograd graph. Existing parameters remain trainable after the context exits.

## Gradient accumulation
Calling `backward()` repeatedly accumulates gradients. Call `zero_grad()` on parameters or the optimizer before starting a new accumulation window.

## SGD momentum and checkpoints
SGD supports optional momentum. `state_dict()` returns hyperparameters and copied momentum buffers; `load_state_dict()` validates parameter shapes before restoring state.

```python
from nucleus import Tensor, no_grad
from nucleus.nn import Linear, Sequential, Tanh
from nucleus.optim import SGD

model = Sequential(Linear(4, 8), Tanh(), Linear(8, 2))
optimizer = SGD(model.parameters(), learning_rate=0.01, momentum=0.9)

# Training: gradients accumulate until explicitly reset.
optimizer.zero_grad()
loss = (model(Tensor([[1.0, 0.0, 0.5, -0.5]])) ** 2).mean()
loss.backward()
optimizer.step()

# Inference: no graph is created.
with no_grad():
    prediction = model(Tensor([[1.0, 0.0, 0.5, -0.5]]))

checkpoint = optimizer.state_dict()
```

This is an educational checkpoint of optimizer state only; model parameter serialization is not included in this milestone.
