# v0.9 Web Interface

The v0.9 interface is a thin application layer over Project Nucleus. The core neural engine remains independent from the web server.

## Endpoints

- `GET /api/status`
- `POST /api/text/train`
- `POST /api/text/generate`
- `POST /api/image/classify`
- `POST /api/audio/classify`

## Security note

The demo server binds to `127.0.0.1` by default. Do not expose it to the public internet without adding authentication, request limits, upload validation, and a production HTTP server.

## Limitations

The browser demos use intentionally tiny datasets and models. Image and audio classification are demonstrations of the Nucleus learning pipeline, not general-purpose classifiers.
