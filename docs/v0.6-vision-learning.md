# Project Nucleus v0.6 — Vision Learning

## Scope

A CPU-first, NumPy implementation of a minimal image-learning path. Images use NCHW layout. The release adds valid (no-padding) Conv2D, max/average pooling, flattening, image normalization and batching, softmax cross-entropy, and a small CNN example.

## Mathematical operations

For valid convolution:

\[Y_{n,o,i,j}=b_o+\sum_{c,u,v}X_{n,c,i s_h+u,j s_w+v}W_{o,c,u,v}.\]

The input gradient accumulates every overlapping receptive-field contribution; weight gradients sum over batch and output positions. Max pooling routes each gradient to the first maximum in its window; average pooling distributes it uniformly.

## Validation

Run `pytest -q` and `python examples/vision_demo.py`. The tests cover tensor shapes, input gradients against finite differences, pooling gradients, dataset batching, cross-entropy gradients, and CNN parameter gradients.

## Limitations

No padding/dilation/groups, GPU kernels, image file decoder, augmentation pipeline, pretrained weights, or benchmark claims. The demo uses a tiny synthetic dataset and is a smoke test, not a general vision benchmark.
