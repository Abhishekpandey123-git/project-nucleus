# v0.5 — Self-Attention Engine

`scaled_dot_product_attention(query, key, value, causal=False)` accepts
`(batch, heads, sequence, head_dim)` tensors and returns context and weights.
Causal mode blocks future positions.

`MultiHeadAttention(model_dim, num_heads)` accepts `(batch, sequence, model_dim)`.
`TransformerBlock` combines pre-normalized causal attention and a feed-forward
network with residual connections. `PositionalEncoding` adds sinusoidal positions;
`LayerNorm` normalizes the feature axis.

This is an educational CPU-first foundation. Embedding integration, dropout,
GPU kernels, and full language-model training are deferred.
