# v0.4 — Character-Level Language Model

Adds a deterministic character tokenizer, sliding-window dataset, mini-batching,
trainable embeddings, a tanh recurrent model, stable cross-entropy, and
autoregressive temperature sampling.

Model equations:
- `h_t = tanh(E[x_t] W_ih + h_(t-1) W_hh + b_h)`
- `logits_t = h_t W_out + b_out`

The model is a small educational RNN, not a Transformer or production LLM.
The current Tensor engine supports 2-D matrix multiplication, so embedding
lookup returns a list of 2-D tensors (one per sequence position). The RNN is
unrolled in Python and intended for short contexts and CPU experiments.
