# Project Nucleus v1.0 — Visual Learning Engine

v1.0 adds the first real visual concept-learning layer on top of the v0.9 multimodal foundation.

## Added

- `VisualDataset` for local class-folder datasets and JSON manifests.
- Safe HTTP(S) image-manifest downloader with an 8 MiB per-image limit.
- `ImageAugmenter` for lightweight self-supervised training views.
- `TinyVisualEncoder`, a trainable NumPy/autograd image embedding model.
- Contrastive learning with positive augmented views and in-batch negative pairing.
- `VisualMemory` for storing embeddings, labels, source paths, nearest-neighbor retrieval, and class prototypes.
- CLI example for training a visual memory from a directory dataset.
- Tests covering encoder gradients and persistent visual memory.

## What v1.0 can do

```text
images
  ↓
augmentation
  ↓
learned visual embedding
  ↓
visual memory
  ├── nearest examples
  └── concept prototypes
```

This is the foundation for later object/animal/human representation learning and image-to-video generation. It does **not** generate images or videos yet.

## Install

Core:

```bash
python -m pip install -e ".[dev]"
```

For JPEG/PNG/WebP image loading:

```bash
python -m pip install -e ".[dev,vision]"
```
