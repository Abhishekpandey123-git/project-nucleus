# v0.9.0 — Web Interface

## Added

- Browser-based Project Nucleus dashboard.
- Text training and generation playground.
- Image upload and small learned vision classification demo.
- Audio upload and STFT-based tone classification demo.
- Dependency-light HTTP server using Python standard library.
- v0.9 web API and regression tests.
- v0.9 documentation and launch example.

## Design goal

Make the existing from-scratch NumPy learning engine directly usable from a browser without introducing a heavy web or ML framework.
