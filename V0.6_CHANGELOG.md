# v0.6 — Vision Learning

- Added NCHW valid Conv2D with manual reverse-mode gradients.
- Added MaxPool2D and AvgPool2D with backward passes.
- Added Flatten, image normalization, ImageDataset, and mini-batch iteration.
- Added stable softmax cross-entropy for integer class labels.
- Added SmallCNN and a reproducible synthetic image-classification demo.
- Added tests for shapes, finite differences, pooling, batching, losses, and CNN gradients.

Limitations: CPU/NumPy only; no padding, dilation, grouped convolution, augmentation, external dataset download, or GPU backend.
