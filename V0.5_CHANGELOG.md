# v0.5 — Self-Attention Engine

- Batched matrix multiplication with broadcast-aware gradients.
- Differentiable reshape and transpose.
- Linear layers accept sequence-shaped inputs.
- Stable softmax, scaled dot-product attention, causal masking, multi-head attention.
- Sinusoidal positional encoding, LayerNorm, feed-forward network, and Transformer block.
- Added tests for tensor gradients, causal masking, attention, normalization, and optimizer updates.

Educational CPU-first foundation. Token embedding integration, dropout, GPU kernels, and full LM training are deferred.
