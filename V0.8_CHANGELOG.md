# v0.8 — Audio Learning

## Added
- Waveform normalization and STFT magnitude spectrogram extraction.
- In-memory `AudioDataset` with mini-batch iteration.
- Trainable spectrogram-based `AudioEncoder` and `AudioClassifier`.
- Stable classification cross-entropy and accuracy metric.
- Synthetic audio classification demo and unit tests.

## Scope notes
This is a NumPy/CPU educational baseline. STFT is preprocessing and is not
differentiable. Speech recognition, text-to-speech, real audio-file decoding,
and audio-text alignment are not included in v0.8.
